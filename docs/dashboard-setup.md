# Accounts Payable Dashboard — Setup Guide

## Overview

This project contains a Power BI Accounts Payable dashboard designed to monitor outstanding invoices, overdue amounts, payment status, supplier exposure, and aging.

## Power BI Project

The repository includes the Power BI Project (`.pbip`) source together with the Report and Semantic Model folders.

## Local Setup

1. Clone or download this repository.
2. Open `Accounts Payable Dashboard.pbip` in Power BI Desktop.
3. Update the data source to point to an approved local or anonymised dataset.
4. Refresh the model.
5. Validate the dashboard KPIs and visuals.

## Data Privacy

Do not publish real supplier names, invoice numbers, payment details, credentials, or confidential financial information.

Use anonymised or sample data for portfolio demonstrations.
